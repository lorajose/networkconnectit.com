Planning Guidance — Not a Code Determination

This helper provides general planning guidance only. It does not determine code compliance, identify the controlling Authority Having Jurisdiction (AHJ), approve a design, establish permit requirements, or replace legal, engineering, architectural, fire/life-safety, accessibility, or other licensed professional review. Always confirm the adopted codes, local amendments, interpretations, permits, inspections, and project-specific requirements with the applicable AHJ and qualified professionals before installation.
