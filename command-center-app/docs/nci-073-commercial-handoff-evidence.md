# NCI-073 — Commercial Handoff Evidence

Use a project containing at least one pre-existing manual takeoff row.

- [ ] Generate design-derived proposal from the intended design revision.
- [ ] Proposal groups/quantities are understandable before approval.
- [ ] Diff is visible before approval.
- [ ] Reviewer identity/time recorded.
- [ ] Apply approved proposal.
- [ ] Existing manual row remains unchanged.
- [ ] Applied design rows retain source design IDs.
- [ ] Rerunning/reapplying does not duplicate the same approved design rows unexpectedly.
- [ ] Takeoff/BOM remains the commercial quantity authority after handoff.
- [ ] Estimate consumes expected quantities.
- [ ] Proposal output traces back to the intended Estimate/design evidence.
