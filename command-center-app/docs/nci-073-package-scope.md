# NCI-073 QA Package Scope

In scope: release-gate documentation, ticket/P0 reconciliation, target-environment runbook, evidence templates, security/client-safe/private-storage risk controls, deployment-gap analysis and a security-test contract protecting critical QA requirements.

Out of scope: claiming runtime PASS without a deployed environment; adding unverified production deployment automation; storing secrets/private customer evidence in Git; closing QA/P0 tickets without their acceptance evidence.
