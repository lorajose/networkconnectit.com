# NCI-073 QA Package

This is the review entry point for the Design Studio release gate.

1. `nci-073-release-blocker-status.md` — current verified state and blockers.
2. `nci-073-master-qa.md` — master acceptance checklist.
3. `nci-073-qa-ticket-reconciliation.md` — implementation-ticket reconciliation.
4. `production-hardening-gate.md` — P0 production/client-safe gates.
5. `nci-073-automated-gate-scope.md` — what CI proves vs. what remains runtime-only.
6. `nci-073-go-live-runbook.md` — target-environment execution steps.
7. `qa-evidence-template.md` — evidence record for each candidate.
8. `staging-deployment-checklist.md` — existing Command Center role/tenant/export smoke-test guide.

No ticket should move from QA/Ready to Done merely because this package exists. The package defines how acceptance is demonstrated.
